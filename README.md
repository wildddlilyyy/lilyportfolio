# Lily Portfolio

Lily 的個人作品集網站，使用純 HTML、CSS 與 JavaScript 製作，整理視覺設計、UI/UX、網站設計、影音剪輯、AI 工具應用與品牌行銷相關作品。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可預覽網站。

## 檔案結構

- `index.html`：網站主要內容與作品資料。
- `styles.css`：版面、RWD 與視覺樣式。
- `script.js`：導覽列、返回頂端、作品分類與區塊偵測互動。
- `assets/`：作品圖片、個人照與 PDF 等素材。

## 維護提醒

- 新增作品時，優先更新 `index.html` 的對應年份區塊。
- 新增圖片或 PDF 時，放入 `assets/`，並確認路徑與替代文字。
- 修改版面樣式時，更新 `styles.css`。
- 修改互動行為時，更新 `script.js`，並確認手機版導覽與分類篩選正常。
